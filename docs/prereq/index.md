# 前置知识 · 课程总览

> 每一课都按同一个套路讲：**它是什么（大白话 + 比喻）→ 动手试一试（10 行以内）→ 常见报错怎么读 → 自测两题**。自测题答案默认折叠，先自己想，再点开对照。

|---|---|---|---|

## 建议的学习顺序

1. **01 → 03**：工具三件套。搭 Wiki 的当晚已经真刀真枪用过它们，学完你会明白当时每条命令在干什么。
2. **04**：随时可学。学完就能开始往 Wiki 里写自己的笔记。
3. **05 → 06**：项目一开工前的地基课。学完这两课，调大模型 API 的每一步你都能看懂。
